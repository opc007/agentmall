技术形态

接入协议MCP（Model Context Protocol），HTTP 端点 /mcp，每请求带 Authorization: Bearer <api_key>
鉴权per-agent key → 角色（用户 / 商户 / 管理员）→ tool 白名单，越权直接拒绝并记审计
前端FastAPI + Jinja2 纯 HTML，零前端框架、零外部 CDN、零构建
支付MockPaymentGateway 模拟网关（PaymentGateway 接口已预留，真实网关上线只换实现类）
数据SQLite（商品 / 用户 / 订单 / 审计日志），演示种子数据

⚠️ 演示边界（必须先说清楚）

  • 商品为演示数据，不是真实货源的实时商品与库存；
  • 支付为模拟支付，不接任何真实支付网关，不产生真实资金流水；
  • checkout hands off：智能体只建单，付款动作永远由用户本人在浏览器里点击完成；
  • 演示订单 is_demo=1，支付后不触发发货，未对接真实履约；
  • 本页演示环境的登录态为简化实现（cookie 直接存 api_key），生产环境将替换为正式 session / JWT。
