# AgentMall MVP 演示脚本（2 分钟版）

> 验收用。按顺序执行，每一步的期望返回见括号内。
> 演示前声明：商品数据为演示数据，支付链接为占位。

## 准备

```bash
pip install -r requirements.txt
python -m agentmall.server
```

将 MCP Server 接入客户端（Claude Code / Claude Desktop / Cursor 任选其一）。

## 演示链路

**第 1 步：搜索**
对智能体说：「帮我找最便宜的抽纸」
- 期望：调用 `search_products(keyword="纸巾")`，返回按价格升序的 8 个纸巾 SKU，
  最便宜的是 P008 一次性棉柔洗脸巾 9.9 元

**第 2 步：比价 + 详情**
对智能体说：「P001 和 P003 哪个划算？」
- 期望：调用 `get_product` 查两个商品详情，
  回答：P001 竹浆本色抽纸 16.9 元/提 vs P003 心相印 22.9 元/包，并算出单抽价格对比

**第 3 步：下单**
对智能体说：「买 2 提 P001，送到广西南宁市朝阳广场」
- 期望：调用 `create_order(product_id="P001", quantity=2, address="广西南宁市朝阳广场")`，
  返回订单号（`AM` + 10 位大写）、`total = 33.8`、`status = "待支付"`、`pay_url` 非空

**第 4 步：查单**
对智能体说：「查一下刚才那个订单的状态」
- 期望：调用 `get_order`，返回该订单，`status` 为"待支付"

**第 5 步（收尾话术）**：
「以上是 AgentMall MVP 的完整链路：搜索、比价、下单、查单。
我们采用 Anthropic 官方蓝图的 'checkout hands off' 范式：
下单是智能体的事，付钱永远是用户的事——智能体只建单，
用户本人在自己的浏览器里点击支付链接完成付款，模型碰不到钱，不做自动扣款。」

## 异常演示（可选，加分项）

- 搜索不存在的关键词如"跑车" → 返回空列表，不崩溃
- `get_order("AM0000000000")` → 返回 `{"error": "找不到订单 ..."}`，不崩溃
